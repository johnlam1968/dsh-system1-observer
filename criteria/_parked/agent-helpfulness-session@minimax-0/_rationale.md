# Parked: refused by the loader, and that is the finding

MiniMax-M3's FIRST authoring of the session scope (2026-10-03, an earlier run of the same brief). Its eight questions
serialize to **4,208 characters, over the 4,000-character cap**, and the loader REFUSES rather than truncating: "a
shortened question returns answers that cannot be matched to what was asked."

So this file is not a set -- it is a specimen. Two things it teaches:

1. **A verbose authoring fails as a set, not as a style.** The two questions per scope in the later authoring fit;
   eight long session questions in one call do not. The cap is per call, because the questions ride on one state.
2. **`_parked/` is where a specimen goes.** The underscore keeps it out of `listSets`, so the corpus invariant --
   every shipped set compiles clean -- is not weakened to accommodate it.

To ship it: trim to fit, or split into two compositions (eight questions is a lot to ask in one call anyway).
